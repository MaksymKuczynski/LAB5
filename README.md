# Лабораторна робота № 5. Основи ООП в Python (Team Project)

## Мета роботи

Розробити об'єктно-орієнтовану систему на Python, яка демонструє основні принципи ООП та навички командної розробки з використанням Git та GitHub.

---

## 📖 Примітка про цей репозиторій

Цей репозиторій містить **робочий приклад** ("Система управління бібліотекою") для демонстрації очікуваної структури проєкту та якості коду. **Ваше завдання — видалити цей приклад та реалізувати один із варіантів, наведених нижче (або власний, узгоджений з викладачем), дотримуючись тієї ж структури та принципів.**

---

## 🤝 Командна робота та взаємодія через GitHub

Ця лабораторна робота виконується в команді з **2-3 осіб**. Кожен член команди має свою роль та відповідальність. Для ефективної співпраці та контролю версій використовується GitHub.

### Вимоги до командної роботи

1.  **Використовуйте GitHub** для спільної роботи над проєктом.
2.  Створюйте **окремі гілки** для розробки різних компонентів системи (`feature/назва-фічі`).
3.  Регулярно робіть **коміти** з інформативними повідомленнями.
4.  Використовуйте **Pull Requests (PRs)** для злиття змін у основну гілку (`main`).
5.  Проводьте **код-рев'ю** змін партнера перед злиттям.

---

## 📝 Завдання для всіх варіантів

Незалежно від обраного варіанту, ваша система повинна реалізовувати наступне:

1.  **Базовий абстрактний клас** (використовуйте модуль `abc`).
2.  Мінімум **два підкласи**, які наслідують базовий клас.
3.  **Клас-менеджер** для управління колекцією об'єктів.
4.  **Інкапсуляція**, **поліморфізм** та **наслідування**.
5.  Магічні методи `__str__` і `__repr__`.
6.  Методи для **пошуку, фільтрації та сортування** об'єктів.
7.  **Модульні тести** (`unittest` або `pytest`) для всіх класів.
8.  **Демонстраційний скрипт ([`main.py`](main.py))**.

## 📜 Варіанти завдань

Оберіть одне із завдань або придумайте своє власне.

### Завдання №1: Архітектор екосистеми
- **Опис:** Створіть симуляцію, де гравці проектують та балансують складні екосистеми.

- **Підкласи:** `Plant`, `Animal`, `Microorganism`
- **Клас-менеджер:** `EcosystemManager`

- **Клас-менеджер:** `GridManager`
